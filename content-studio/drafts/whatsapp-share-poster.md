# WhatsApp share — Full-Stack AI Engineer poster + forward message

The paired copy that travels **with** `exports/whatsapp/Eduflick_FullStackAI_WhatsApp.jpg`
(the all-in-one `poster-whatsapp` tile). Built to be forwarded into college / B.Tech batch
groups, dev communities, and 1:1 DMs **without** reading as spam.

> **Voice rules honoured** (from `whatsapp-sequence.md` + the forwardability research):
> calm, concrete, retypeable, **one ask**, no emoji spam (≤1 functional `→`), no exclamation
> hype, **no deadline** (scarcity is seat-count only), no "Certified", no placement %, no
> fabricated alumni. Every number/link is verbatim from `FACTS.md`. The apply URL is allowed
> on WhatsApp (unlike Instagram).
>
> **The poster stands alone** if a caption gets stripped on forward — the trust facts (3 deployed
> projects · real stack · UXP Innovation Hub, Trivandrum · 20 selective seats · apply URL) are all
> on the canvas. The messages below just give a peer a clean reason + clean words to send it.

## How to send it

1. **Attach** `exports/whatsapp/Eduflick_FullStackAI_WhatsApp.jpg` (1080×1350, ~134 KB — already
   under WhatsApp's ~1600px / re-encode ceiling, so it stays crisp; **send as Photo, not Document**,
   for the inline preview that previews fully in a 4:5 chat bubble).
2. **Paste** the matching message above as the caption (or the peer caption for a cold forward).
3. **One ask only.** If they reply, move to the `whatsapp-sequence.md` nurture flow (confirm →
   remind → offer → scarcity → close). Urgency is seats-left, never a date.

**Re-render the image:** `cd tools && npm run export:whatsapp`
(crisp 2× PNG → `exports/posters/poster-whatsapp.png`; share JPEG → `exports/whatsapp/`).
