# QA checklist — the gate every piece passes before it ships

Run this on any draft (yours or a model's). It's written so you can **paste it straight to a small
model** and say: *"Score this draft 0–100 using this checklist. List every ✗ with the exact line,
then rewrite only the failing lines."*

A piece ships at **≥ 85** with **zero hard-fails**.

---

## A. HARD FAILS (any one = do not ship, fix immediately)

- [ ] **No invented facts.** Every date, price, seat count, link, name, time appears in the FACTS
      block. Anything else is a `[[NEEDS: …]]` placeholder, not a guess.
- [ ] **No emoji** anywhere in finished public copy. (WhatsApp: at most one, rarely.)
- [ ] **No forbidden words:** level up, unlock, boost, supercharge, gamechanger, claim reward,
      world-class, revolutionary, hurry, "limited time", "don't miss out".
- [ ] **Sparks are earned**, never "unlocked/leveled/claimed."
- [ ] **Factually correct** about the program: in-person · Technopark/UXP Trivandrum · capped at
      20 · 12 weeks · Pioneer ₹49K vs ₹70K · free masterclass is the top-of-funnel.
- [ ] **Right brand face** (program vs product) for the task.

## B. VOICE (target ≥ 35 / 40)

- [ ] Reads like an **engineer**, not a marketer. Confident, technical, no fluff.
- [ ] **Short, declarative** sentences; fragments OK; cuts to the verb.
- [ ] At least one **number as proof** (60s, 20 seats, 3 projects, ₹49K, 12 weeks…).
- [ ] Speaks to **"you"**; brand is "we." No "the user," no "dear students."
- [ ] **"Flick"** used naturally where relevant (product copy especially).
- [ ] No exclamation-mark hype; scarcity is stated as a number, calmly.

## C. FORM & CASING (target ≥ 25 / 30)

- [ ] **Display/headline is lowercase.** Mono labels/eyebrows are UPPERCASE. Body is sentence case.
- [ ] **Exactly one (max two) serif-accent word**, marked with `*asterisks*`, on the payoff word.
- [ ] Wordmark written `eduflick AI` / `eduflickAI` (lowercase + uppercase AI).
- [ ] Hits the **format spec** for the channel (length, slide count, caption shape — see CHANNELS.md).
- [ ] Hashtags (if any): **3–6**, precise, from the cheat-sheet pool. No grind/motivation tags.

## D. STRATEGY (target ≥ 20 / 30)

- [ ] Ladders to **one content pillar** (Build in Public / Get Hired / Learn Fast / The Cohort /
      Pioneer Urgency).
- [ ] **One clear CTA**, matched to the funnel phase (awareness → register free; conversion → book seat).
- [ ] **Hook in the first line** (it has to survive feed truncation).
- [ ] If audience-facing: mirrors a real **audience pain** ("I know React but never built with LLMs," etc.).
- [ ] Adds something — a proof, an angle, a number — not just a restated tagline.

## Scorecard (for the model to fill)

```
SCORE: __ / 100
  Hard fails (A):      [none] OR list each with the offending text
  Voice (B):           __ / 40
  Form & casing (C):   __ / 30
  Strategy (D):        __ / 30
VERDICT:  SHIP  |  FIX  (ship only if ≥85 AND zero hard-fails)
FIXES:    rewrite ONLY the failing lines below, keep everything that passed:
  - ...
```

---

## Fast human pass (10 seconds, no model)

Read it out loud. If it sounds like a LinkedIn-influencer or a course ad → fail. If it sounds
like a sharp engineer stating facts → pass. Then scan for: emoji, a made-up number, Title Case,
and a missing CTA. Those four catch ~90% of misses.
