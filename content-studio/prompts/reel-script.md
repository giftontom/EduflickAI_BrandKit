# Prompt — Reel / YouTube Short script

Load `00_SYSTEM_PROMPT.md` first. Same template for IG Reels and YT Shorts (set the platform).
Output is shootable: a hook, timed beats, voiceover, on-screen text, and shot notes.

---

```
FACTS (only source of live numbers — never invent; missing → [[NEEDS: …]]):
- Masterclass date / cohort start / seats left: [[ ]]
- Registration link / WhatsApp:                  [[ ]]
- Price / venue:                                 [[₹49,000 / UXP Innovation Hub, Trivandrum]]

TASK:
- Platform: [[IG Reel | YouTube Short]]      Length: [[≤30s | ≤60s]]
- Idea: [[e.g. "I built an AI chatbot in 8 weeks" | "theory vs shipping" | "what is RAG in 60s"
  | "day in the cohort" | "what you build in week 8"]]
- Pillar: [[ ]]   Funnel phase: [[ ]]   POV: [[student | founder | faceless screen-recording]]

CONSTRAINTS (priority order):
1. HOOK in the first 1.5 seconds — a line that stops the scroll (a claim, a number, or their pain).
   Put it both as spoken VO and as big on-screen text.
2. 3–5 fast beats. Each beat = a timestamp, the VO line, the ON-SCREEN text, and a shot note.
3. Show, don't tell: real editor, deployed UI, the cohort room, terminal — never stock footage.
4. End on ONE CTA + a cover-frame line for the thumbnail. CTA matched to funnel phase.
5. VO = engineer voice: short, declarative, a number in it. On-screen text is lowercase; mono
   labels UPPERCASE. No emoji. No forbidden words.
6. Keep total VO word count realistic for the length (~2.5 words/sec).

OUTPUT (exactly this):
TITLE / CONCEPT:
COVER FRAME (thumbnail line, lowercase, one *serif* word):
HOOK (0:00–0:02):  VO: "…"   |  ON-SCREEN: "…"   |  SHOT: …
BEAT 1 (0:02–0:0X): VO / ON-SCREEN / SHOT
BEAT 2: …
BEAT 3: …
CTA (0:XX–end):    VO / ON-SCREEN / SHOT  + link from FACTS
CAPTION: hook + 2 lines + CTA + 3–5 hashtags
```
