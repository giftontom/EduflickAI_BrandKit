# \_ref/ — local reference material

Inputs that informed the kit but are **not part of it**. Binaries here are
gitignored (`_ref/*.zip|png|jpg`) — they stay on disk locally but don't ship
with the repo.

What lived here when this README was written:

| File | What it was |
| --- | --- |
| `Eduflick AI Design System (1).zip` | The original design-system handoff archive the kit was built from |
| `screenshot_ref.png` / `.jpg` | Visual reference screenshots used during the brand-book build |
| `screens/` | Render screenshots of built artifacts (brochure covers, IG grid) kept for visual reference — tracked, small |

For *archived previous versions* of shipped artifacts (old brand-kit HTML),
see [`../_archive/`](../_archive/) instead.
